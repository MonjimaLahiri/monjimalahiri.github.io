# Fresh Portfolio Starter

This is a minimal static starter for `monjimalahiri.github.io`. Edit `index.html`, `styles/style.css`, and `scripts/main.js` to build your portfolio.

## Local preview
Just open `index.html` in a browser. No build tools required.

## Deploy (GitHub Pages via Actions)
- This repo includes `.github/workflows/pages.yml` which publishes on every push to `main`.
- If you prefer branch deploys instead: Settings → Pages → Deploy from branch → `main` → `/ (root)`.
